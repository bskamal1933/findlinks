# findlinks
This extention will check all the links in the base URL and check the link is active and working. Also finds the non working links.

Download miniconda from this command:
curl https://repo.anaconda.com/miniconda/Miniconda3-latest-Windows-x86_64.exe -o miniconda.exe
Start-Process -FilePath ".\miniconda.exe" -ArgumentList "/S" -Wait
del miniconda.exe
